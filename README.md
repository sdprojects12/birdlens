# BirdLens 🐦

BirdLens is an AI-powered bird identification web application that allows users to upload a bird photograph and receive species predictions along with taxonomy data, recent sightings, conservation information, and additional species details.

Built using Flask, BioCLIP, eBird, Wikipedia, and iNaturalist APIs.

---

## Features

### AI Bird Identification

* Upload a bird photograph
* Species prediction powered by BioCLIP
* Top candidate predictions with confidence scores

### Species Information

* Common and scientific names
* Taxonomic classification
* Family, genus, and order information

### eBird Integration

* Recent sightings by region
* Species codes and taxonomy data
* Direct links to eBird species pages

### iNaturalist Integration

* Observation counts
* Conservation information
* Direct links to iNaturalist species pages

### Modern Interface

* Responsive two-panel layout
* Image preview before identification
* Interactive result cards
* Dark nature-inspired design

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/BirdLens.git
cd BirdLens
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file or set the following environment variable:

```env
EBIRD_API_KEY=your_api_key_here
```

BirdLens requires an eBird API key for taxonomy and sighting data.

## How It Works

1. User uploads a bird image.
2. BioCLIP generates species predictions.
3. The highest-confidence prediction is selected.
4. Additional information is fetched from:

   * eBird
   * Wikipedia
   * iNaturalist
5. Results are displayed in an interactive dashboard.
